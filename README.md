# Kitty 🐱🔗

**Let your AI agents spend. On a leash.**

Kitty is a group kitty (trips, offsites, weddings) that AI agents can spend on your behalf — but every agent holds a **Leash**: a prefunded, revocable PayPal spending pass with per-payment, daily and total limits, approved payees, allowed actions, an expiry and step-up approval. Even a fully hijacked agent can move at most its leash balance, and only to payees the organizer approved.

Inspired by the agent-pass concept Sui introduced at Basecamp 2026, rebuilt for PayPal.

> 🚧 Work in progress for the [PayPal AI Hackathon](https://paypalaihackathon.devpost.com/). Planning docs (Vietnamese) live in [`docs/`](docs/) — start with [`AGENTS.md`](AGENTS.md).
